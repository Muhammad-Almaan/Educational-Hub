# Educational Hub 🎓

A Flask website that mixes creativity and science, with two projects in one.

## Features
- **Poetry Generator:** enter 5 words and get a sonnet, free verse, haiku or rhyming poem
- **Seasons Explorer:** animated lessons on why the seasons change, with a random fact button and a mini quiz

## Tech Stack
Python, Flask, Flask-CORS, HTML, CSS, JavaScript

## Run Locally
```
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```
Then open http://localhost:5000
